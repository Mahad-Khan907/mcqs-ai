## PART 2: ANSWER KEY & PSYCHOMETRIC DISSECTIONS

### Question 1 — Evaluation & Analysis
- **Target Domain:** Domain 4: Workflow Integration and Solution Design
- **Sub-Topic Grounding:** Chat Box vs. Agent Surface Operational Distinction (Concept 1: Same address, two different things (Lines 347-372))
- **Correct Answer:** **Option D**

#### Psychometric Rationale & Source Grounding
Option D is uniquely accurate per Section 1. The defining test separating a chat box from an agent surface is: 'If I stop typing, does the work stop? Chat box: yes. Agent surface: no.' Plain chat is synchronous and requires the user to initiate every turn. An agent surface is delegated; once assigned an outcome, it plans, uses tools, and keeps working even if the user stops typing or closes the tab.

#### Distractor Analysis & Operational Traps
- **Option A Flaw:** Option A is incorrect because concurrent session token management is an authentication rule, not the test for delegated execution.
- **Option B Flaw:** Option B is incorrect because web chat interfaces do not revert to command-line prompts when end-users interact without developer API keys.
- **Option C Flaw:** Option C is incorrect because responsive CSS text reflow is a front-end rendering behavior unrelated to agentic delegation.

### Question 2 — Evaluation & Analysis
- **Target Domain:** Domain 3: Product and Model Selection
- **Sub-Topic Grounding:** The Two-Axis Runtime Model (Concept 2: The remote session: the tab is a window, not the runtime (Lines 381-395))
- **Correct Answer:** **Option D**

#### Psychometric Rationale & Source Grounding
Option D is uniquely accurate per Section 2. The chapter instructs operators to separate two runtime questions: Axis 1 (where does the agent loop run?) and Axis 2 (where does each tool execute?).
